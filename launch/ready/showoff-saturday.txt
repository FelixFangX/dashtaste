Title:
[Showoff Saturday] Six named dashboard tastes + a 38-rule ECharts linter for coding agents

Body:
Coding agents can spin up an ECharts dashboard in minutes, and it almost always lands on the same default rainbow look: multi-colour pies, smooth lines with a dot on every point, truncated bar axes, six emoji KPI cards, a legend for one series. None of that fails unit tests.

Dashtaste makes dashboard taste a checkable loop instead of one shared palette:

- Six named tastes: `saas-dense`, `exec-brief`, `ops-wall`, `cn-ecommerce`, `global-marketplace`, and `editorial-data` (each pairs tokens with layout caps; `global` and `cn` packs differ on delta colour conventions, K/M/B vs 万/亿, and 1920×1080 screens).
- `npx dashtaste check dashboard.json --taste saas-dense` checks ECharts JSON or rendered pages (local Chromium + optional `playwright-core`) against 38 rules (`DT001`–`DT038`), tagging each finding as `constraint`, `heuristic`, or `taste`, with path, fix, 0–100 score, and JSON output for CI/agents.
- Agent-ready via skills (`npx skills add FelixFangX/dashtaste --skill dashtaste`) or stdio MCP (`npx -y dashtaste mcp`).

Live 6-taste demo + interactive browser checker: https://dashtaste.ledring.dev
Gallery pairs share fictional seeded data (rule consistency, not a UX study). Sibling project for web maps: maptaste (https://maptaste.ledring.dev).

MIT · npm `dashtaste` · v0.0.8 · ECharts-only for now.
