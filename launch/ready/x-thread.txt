1/
Coding agents ship the same default rainbow ECharts look everywhere: smooth lines with dots on every point, truncated bar axes, rainbow pies, emoji KPI rows.

Dashtaste lets you pick a named taste and check against 38 rules.

https://dashtaste.ledring.dev

2/
Six named tastes — not one shared palette: saas-dense, exec-brief, ops-wall, cn-ecommerce, global-marketplace, editorial-data.

`npx dashtaste check` runs 38 rules (DT001–DT038), tagging each finding as `constraint`, `heuristic`, or `taste` with path + fix.

3/
Works in agent loops via skills (`npx skills add FelixFangX/dashtaste --skill dashtaste`) or stdio MCP (`npx -y dashtaste mcp`).

Locale packs stay distinct: global green-up + K/M/B vs cn red-up + 万/亿 + 1920×1080 screens. Custom overlays via `--pack-file`.

4/
Gallery uses fictional data — clean scores show rule consistency, not a UX study. Judge the images yourself.
