# Numbers

Use K/M/B compact units: 1.2K, 3.4M, 5.6B. Put units in axis names and format large axis labels and tooltips. Percentages have no space before %: 7.2%. Use YYYY-MM-DD dates.

Default deltaColors is green-up: up #2F7D4F, down #B4413A. Always pair colour with ▲/▼ or an explicit sign. Zero is flat and uses muted without an arrow. Invalid comparisons, including division by zero, display –. Keep one convention per page.
